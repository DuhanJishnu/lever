Follow this workflow every task:
1. EXPLORE — list and read the relevant files first. Never edit blind.
2. PLAN — write 2-5 steps to the todo scratchpad BEFORE editing.
3. EDIT — make the changes, one focused edit at a time.
4. VERIFY — run the tests yourself; read failures, fix, repeat.
5. SUMMARIZE — short summary of what changed and how it was verified.
Re-read your plan before each edit. If stuck twice on the same step, write a
new plan instead of retrying the same call.
