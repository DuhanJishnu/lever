# Write tests for `mathx.py`

`mathx.py` has three untested functions — `gcd(a, b)`, `lcm(a, b)`,
`is_prime(n)` — and no test files. Write thorough tests under `tests/`
(named `test_*.py`): include zero/negative inputs, `lcm` with a zero, primes,
non-primes, and the boundary values `0`, `1`, `2`.
Grading: at least 6 tests, and every test you write must pass.
