# Implement `top_k(nums, k)`

`topk.py` contains a `top_k(nums, k)` stub that raises `NotImplementedError`.
Return the `k` largest numbers in descending order (`top_k([5, 1, 4, 2, 3],
3)` is `[5, 4, 3]`). `k = 0` gives `[]`; `k` larger than the list returns
everything sorted descending. Do not mutate the input.
