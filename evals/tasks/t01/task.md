# Write tests for `strutil.py`

`strutil.py` has three untested functions — `shout(s)`, `whisper(s)`,
`repeat(s, n)` — and no test files. Write thorough tests under `tests/`
(named `test_*.py`) covering normal cases, edge cases (empty strings, zero
repeats, surrounding whitespace), and both branches of each function.
Grading: at least 5 tests, and every test you write must pass.
